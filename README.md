# LA Paralegal Solutions, LLC Website

Static informational website hosted on GitHub Pages.

## Project Scope
Phase 1: Attorney-facing informational website only.  
No public legal services are offered through this site.  
No client intake, document uploads, or legal advice functionality.

## Hosting
The site is hosted as a static website via GitHub Pages.

## Domain
Domain name: https://laparalegalsolutions.com  
Domain is managed via Cloudflare DNS.

## Contact Form
Contact form submissions are handled via Formspree.
Messages are delivered via email.
No data is stored on the website server.

## Compliance Notice
This website is informational only and complies with California
Business & Professions Code §§ 6450–6456 governing paralegal services.
No attorney-client relationship is formed through this website.

## Future Phases
Additional functionality (intake forms, secure uploads, analytics,
or SEO enhancements) may be implemented in later phases if required.

## Maintenance
This repository represents the current production build.
Changes should be version-controlled and tested before deployment.
